Regionalization of Acute Stroke Care for Rural Populations: A Systems Modeling Approach (R01MD018031)

Data Pipeline Overview

What we proposed to do

Our objective is to develop a decision-analytic systems model that allows stroke system planners to compare potential effects of regionalized EMS triage and transport strategies on rural stroke outcomes and health care resource utilization. Decision-analytic modeling is a rigorous and flexible approach for integrating information sources to conduct in silico testing of system-level strategies under varying contexts. This comparative evidence provides valuable and timely information to decision makers to tailor interventions for real-world implementation and evaluation. Using existing real-world data sources, published evidence, and key stakeholder input, we will build a computer simulation model of regionalized stroke care in rural North Carolina.

How statewide data inform the simulation model

This project uses a discrete event simulation model to compare the effects of alternative EMS stroke triage and transport protocols on patient outcomes and health care resource use within 70 rural North Carolina counties. Because the model must reflect local heterogeneity, linked data on prehospital EMS encounters, emergency department visits, and inpatient admissions are analyzed to quantify stroke care processess and outcomes throughout the continuum of care. Specifically, this integrated dataset is used to parameterize and validate the simulation model.

What we do with the data

We originally proposed to link statewide data from the NC EMS Data System (from the NC Office of EMS) and the statewide hospital discharge data (from the Sheps Center). There are no direct patient identifiers in these data, so we use an iterative linkage strategy matching on dates, facility names, and patient age/sex/race.

Since the ED visits data from Sheps does not differentiate whether a patient arrived by EMS ambulance or other means, preliminary linking found numerous many:1 matches. Now we propose to use the 'arrival mode' data element in NC DETECT by matching NC DETECT data to the state ED dataset and then filtering on EMS arrivals. Secondly, the disposition variable in the state ED dataset appears unreliable, so we will retain the 'ED disposition' variable from NC DETECT. These steps will be performed by Matthew Kerber of the Carolina Center for Health Informatics (CCHI).

Potential alternative strategies

If the above in its entirety is not allowed, there may be other approaches that could still provide valuable information to achieve the project goals. For example, we could remove identifiable geographic and time variables from the EMS data and replace with derived deidentified variables. If EMS data cannot be used at all, we could link the NC DETECT data to state ED to derive aggregate estimates of EMS arrivals for stroke and ED dispositions. There are several alternatives that could support the project's data needs and remain compliant with Shep's agreements with the state data owners.
